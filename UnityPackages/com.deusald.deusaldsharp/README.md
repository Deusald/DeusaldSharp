# DeusaldSharp

Meta-package: no code of its own, installs every DeusaldSharp module package (`com.deusald.deusaldsharp.core`,
`com.deusald.deusaldsharp.vectors`, ...). Install it to get everything, or install only the modules you use.

Recommended: install from OpenUPM (signed packages, dependencies resolved for you):
https://openupm.com/packages/com.deusald.deusaldsharp/

Git URL: add each module from its own folder, together with the modules it depends on:
https://github.com/Deusald/DeusaldSharp.git?path=/UnityPackages/com.deusald.deusaldsharp.core#vX.X.X

Documentation and installation details: https://github.com/Deusald/DeusaldSharp#installation
