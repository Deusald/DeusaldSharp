DeusaldSharp 11.0.2 contains no library changes compared to 11.0.1. See the
[11.0.1 release](https://github.com/Deusald/DeusaldSharp/releases/tag/v11.0.1) for the full 11.x patch notes.

## Packaging

- Every package includes the readme, so module documentation is shown on its NuGet.org page.
- The `DeusaldSharp` meta-package no longer ships an empty symbol package.
