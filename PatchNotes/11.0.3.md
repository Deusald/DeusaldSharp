DeusaldSharp 11.0.3 contains no library changes compared to 11.0.2. See the
[11.0.1 release](https://github.com/Deusald/DeusaldSharp/releases/tag/v11.0.1) for the full 11.x patch notes.

## Packaging

- Releases are published to a static NuGet feed on GitHub Pages that needs no credentials:
  `https://deusald.github.io/DeusaldSharp/index.json`. New versions are available there within minutes of the
  release build.
- The release workflow uses Node.js 24 actions.
